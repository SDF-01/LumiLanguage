# Japanese Path Curriculum

## Path order (from zero)

1. **START HERE** — no kana yet: welcome, sounds (romaji + audio), three scripts, bridge into hiragana
2. **Hiragana** — full basic chart (あ〜ん)
3. **Katakana** — full basic chart (ア〜ン)
4. **Kanji** — meaning characters (starter set)
5. **Phrases** — greetings and particles

## Scripts covered

1. **Hiragana** (phonetic)
2. **Katakana** (loanwords / emphasis)
3. **Kanji** (meaning characters)

## Lesson skill order (every unit after foundations)

1. **Read**
2. **Write** (character selection / form recognition for MVP)
3. **Speak** (repeat after TTS; self-check)
4. **Listen** (TTS → choose)
