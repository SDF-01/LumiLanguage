# Use Case Specification — TOEIC / Japanese Dual-Path Learning App

## Business Problem

Japanese learners need a structured, exam-aligned path to score 800+ on TOEIC, covering Listening (Parts 1–4) and Reading (Parts 5–7) with original practice content, English→Japanese explanations, and timed practice exams. English speakers need a parallel path to learn Japanese from elementary through advanced (read, write, speak). Both paths should feel like an interactive retro game on mobile-first devices, with TTS for listening/speaking drills. Official ETS materials are not copied; content follows TOEIC criteria and formats with original items only.

## Primary Users

Japanese TOEIC candidates (target 800+), English-speaking Japanese learners (elementary→advanced), self-paced mobile learners using short daily sessions

## Success Tenets

1. **Exam fidelity** — TOEIC vertical slice matches official part structure, timing conventions, and skill focus (original items only); learners can complete tutorial → exercises → checkpoint with clear scoring feedback.
2. **Dual-path completion** — Both TOEIC and Japanese slices are playable end-to-end on a phone (one hand, thumb-reach CTAs, working TTS audio controls).
3. **Retention loop** — XP/progress persists locally across sessions; learners can resume a unit and see streak/XP without accounts in the MVP.
